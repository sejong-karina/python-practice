# python-practice

## 사칙연산 계산기

`calculator.py`는 숫자 두 개를 입력받아 덧셈, 뺄셈, 곱셈, 나눗셈을 수행하는 간단한 프로그램입니다. 나눗셈에서 두 번째 숫자가 0이면 오류 메시지를 표시합니다.

### 실행 방법

1. Python 3가 설치되어 있는지 확인합니다.
2. 터미널(명령 프롬프트 또는 PowerShell)에서 이 저장소 폴더로 이동합니다.
3. 아래 명령을 실행합니다.

```bash
python calculator.py
```

4. 안내에 따라 숫자 두 개와 연산자(`+`, `-`, `*`, `/`)를 입력합니다.

예를 들어 `8`, `2`, `/`를 차례로 입력하면 `결과: 4.0`이 출력됩니다.
